# 柚子 · 电子女友 AI 伴侣（开源模板）

一个开箱即用的**本地部署陪伴型 AI** 项目。填好配置向导、接入你自己的大模型 API，就能得到一个会主动问候、记得你、会连发消息、能识别图片和表情的"电子恋人"。

> 本模板不包含任何人的真实密钥、QQ 号或聊天记录，全部由你自己配置。

---

## 它能做什么

| 能力 | 说明 |
| --- | --- |
| 角色人设 | 固定人设（默认「柚子」），强情绪向、会共情，不反复自称 AI |
| 时间感知 | 自动感知当前日期、时段（早/午/晚/深夜），问候语随时间段变化，不编造天气 |
| 情绪感知 | 自动识别对方情绪（低落/开心/生气/闲聊），动态调节语气：倾诉就哄、闲聊不腻 |
| 随机连发 | 像真人一样偶尔连发 2~4 条短消息、随机带颜文字/表情，每次回复都不一样 |
| 动态长短 | 看情境定回复长度：对方只发一两句→你也简短；倾诉长文/低落→多说几句稳稳接住 |
| 有自己的脾气 | 低频、克制地不完全顺着对方：半开玩笑顶一句、撒娇、小小任性（有分寸，不伤人） |
| 主动问候 | 每隔一段时间主动发消息关心你（默认 2 小时，可改间隔、静默时段；后台页可手动触发测试），偶尔连发多条 |
| 多模态 | 发图片→自动识别内容；QQ 表情→转文字；分享视频链接→解析标题/作者/时长；本地视频→抽帧看懂画面 |
| 语音回复 | 回复可转成语音（网页端带 🔊 播放按钮） |
| 记忆 | 记住你说过的事、个人状态；带**遗忘曲线**（长时间不提会淡忘） |
| 好感/性格 | 聊天会累积好感度、熟悉度，性格动态演变 |
| 长期档案 | 结构化画像（生日/工作/喜好…）+ 关系事件时间线（表白/纪念日/生病）+ 旧对话自动摘要归档，聊得越久越懂你 |
| 成长曲线 | 管理后台实时画好感度成长曲线、记忆遗忘曲线示意、关系历程时间线 |
| 话题延展 | 回复不呆板：聊得顺时自然延展话题、有来有回；倾诉/低落时专心接情绪不岔开 |
| 真贴纸表情包 | 回复后按概率单独发一张图片贴纸（16 款可爱透明 PNG），不再用 [表情/xx] 文字式 QQ 表情 |
| 管理后台 | 网页端可微调人设、查看好感/性格、管理记忆库、手动触发主动问候 |
| 多通道 | 网页聊天、QQ 官方机器人、QQ 备用号(NapCat)、微信公众号 |

## 一、环境要求

- Windows 10/11
- Python 3.10+（已装 `flask requests pyyaml websocket-client`，用下方脚本一键装）
- 至少一个大模型 API Key：**DeepSeek**（对话）推荐；**阿里云百炼**（语音/图片识别，可选但强烈推荐）

## 二、快速开始（5 分钟）

```powershell
# 1. 安装依赖
pip install -r requirements.txt

# 2. 生成配置
#    双击打开 setup.html，按向导填写你的 API Key（DeepSeek + 可选阿里百炼）
#    向导会自动生成 .env 放到项目根目录

# 3. 启动
.\run.ps1
```

浏览器打开 **http://127.0.0.1:8000** 就能和柚子聊天；
打开 **http://127.0.0.1:8000/admin** 是管理后台（人设微调 / 好感 / 性格 / 记忆库）。

## 三、三种接入通道（任选其一，可并用）

### 1. 网页端（最简单，零配置）
填好 DeepSeek Key 后直接聊天即可。

### 2. QQ 官方机器人（合规稳定，可主动推送）
1. 到 [QQ 开放平台](https://q.qq.com) 注册应用，拿到 **AppID / AppSecret**
2. 在 setup.html 里填上，勾选启用 QQ
3. 用户通过官方机器人的入口（如 QQ 频道/单聊）发消息即可
> 注意：平台侧"AI Agent 接入"开关如果开了，会拦截消息，记得关掉

### 3. QQ 备用号（NapCat + OneBot）
让**一个真实 QQ 号**成为 AI，体验更像真人好友：
1. 下载 [NapCat](https://napneko.github.io)（Windows），解压后用管理员运行
2. 用你的 QQ 号扫码/密码登录，得到 `config` 目录
3. 写一份 OneBot11 配置：`websocketServers` 开一个 WsServer，监听 `0.0.0.0:3001`，设 token
4. 在 setup.html 里填 `ONEBOT_WS_URL=ws://127.0.0.1:3001`、`ONEBOT_ACCESS_TOKEN=你的token`，勾选启用
5. 重启 NapCat，项目会自动连上并收发消息

### 4. 微信公众号（可选）
填 `WECHAT_TOKEN` 等字段即可。

## 四、配置项速查（.env）

关键项见 `.env.example`。常用调优：

```ini
LLM_TEMPERATURE=0.85          # 越高越活泼，纯闲聊可调低到 0.7 更稳
PROACTIVE_INTERVAL_MINUTES=120 # 主动问候间隔（分钟）
PROACTIVE_QUIET_START=23       # 静默时段开始（23点后不打扰）
PROACTIVE_QUIET_END=8          # 静默时段结束
KAOMOJI_PROB=0.30              # 回复末尾带颜文字的概率（0~1）
MEMORY_THRESHOLD=0.3           # 记忆遗忘阈值（越低记得越久）
MEMORY_HALF_LIFE_DAYS=7        # 记忆半衰期（天）
TTS_VOICE=Cherry               # 语音音色
```

### 主动问候怎么测试？

管理后台（/admin）新增了 **「立即发一条问候」** 按钮，点一下立刻生成并发送一条主动消息，不用等 180 分钟；也可以直接调接口 `POST /api/proactive/trigger`。

## 五、自定义你的"柚子"

编辑 `personas/youzi.yaml`，可改名字、性格、回复规则、底线。
或直接打开管理后台 http://127.0.0.1:8000/admin 在页面上改，保存即生效。

## 六、目录结构

```
app/                后端源码（配置/大模型/人设/记忆/语音/主动问候/好感/视觉 + 适配器）
  adapters/         onebot(QQ备用号) · qq_official(QQ官方) · wechat_mp(微信公众号)
  static/           index.html(聊天页) · admin.html(管理后台)
personas/youzi.yaml 人设文件
data/               数据库与运行状态（自动生成）
setup.html          配置向导
run.ps1             启动脚本
.env.example        配置示例
```

## 七、常见问题

- **回复太浓/太腻？** 在管理后台把"情绪浓度看场合调节"调强，或手动改 youzi.yaml
- **想让它更黏人？** 改 personality 里的"黏人度"滑条
- **主动消息没来？** 检查静默时段（23:00-8:00 不主动）、`PROACTIVE_ENABLED=true`
- **备用号连不上？** 确认 NapCat 已用同一 token 配置、端口 3001 在监听

## 八、安全与边界

本项目仅供个人学习使用。请勿用于骚扰、冒充或诈骗他人；不索取用户密码/验证码/转账。使用第三方 API 请遵守其服务条款与当地法律法规。

## 表情包 / 头像素材

仓库为控制体积**不直接存放二进制素材**（贴纸 PNG / 动图 GIF / 头像）。模板自带 `assets_pack.py` 恢复脚本：

```bash
python assets_pack.py
```

运行后会从内嵌 base64 还原全部素材到 `data/stickers/`、`data/gif_library/`、`app/static/avatar.jpg`。
如果你不用贴纸表情功能，也可以跳过这一步——代码会自动降级（无素材就不发贴纸，其余功能不受影响）。
