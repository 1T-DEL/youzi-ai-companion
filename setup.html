大模型接口

整条链路的发动机
i
只认 OpenAI 兼容的 Chat Completions 接口，不锁厂商。三项都留空也能启动，只是会用本地演示回复。

只填地址和模型名，密钥仍需你自己粘。

通常以 /v1 结尾，末尾不要带斜杠。

按服务商控制台给的填。这条会明文写进 .env，别把 .env 传给别人。

必须是服务商真实存在的模型 id，写错会一直报 404。

陪伴型角色建议 0.7–0.9，太低会像客服。

微信聊天语感要短，500 左右足够。

公众号被动回复有 5 秒硬限制，见第 4 节说明。

每轮带多少条上下文。越大越贵，也越慢。

防刷也防账单爆炸。

填了才能把语音消息转成文字，留空则语音功能自动降级关闭。

2

人设

决定「她是谁」，写这块最影响体感
i
这些字段会生成一份 personas/<id>.yaml，程序每次回话前都会读它。改这里＝改角色，不用动代码。

英文小写，决定 yaml 文件名。默认 youzi → 生成 youzi.yaml。

她自称的名字，聊天里会频繁出现。已按默认偏好填「柚子」，可改成你喜欢的名字。

一句话交代她「是什么」。填得越诚实，越不容易出戏式翻车。

建议包含一句「不假装有真实身体」之类的边界 —— 这是长期不翻车的关键。可改成你们之间的专属故事。

想要「活泼元气」就往下加：语气轻快、有精神、会主动分享小情绪。

明确她不做什么，能挡掉一大批越界请求。

3 句最像真人微信。

第一条决定「情绪优先还是讲道理」，是这类角色的核心开关。

强烈建议原样保留，尤其最后一条。

QQ 接入

两条路，选一条即可
推荐QQ 官方机器人

走腾讯开放平台，合规、稳定、可主动推送。需要注册应用拿 AppID / AppSecret。

可选OneBot 11

接现成的 QQ 适配器 WebSocket 服务。本项目只管连接，不管造适配器。

QQ 开放平台 → 应用管理 → 机器人资料卡。

只显示一次，记下来收好。

默认 33554432 只开私聊事件；要收群 @ 再按控制台给的值调整。

正向或反向 WS 都填这里，以适配器显示为准。

适配器没设就留空。

!
以个人 QQ 号自动收发消息属于平台灰区，账号有被限制的风险。请确认自己有权操作该账号，并自担后果。
4

微信接入

公众号回调 或 自建网关
合规微信公众号

被动回复，受 5 秒超时限制；不能任意主动推送，主动消息会进 outbox 排队。

需自备自建微信网关

你有一台已获授权的网关时填这里，可支持双向收发与主动推送。

做不到个人微信原生通话

平台不开放实时语音通话接口，任何「直接接管微信通话」的说法都不成立。

i
想让微信侧真正跑起来，需要把本机端口映射到公网 HTTPS（cloudflared / ngrok 之类），回调地址填 https://你的域名/wechat/callback，加解密先选明文模式。

两边必须一模一样，否则微信会直接拒收。

必须小于 5，留 0.5 秒余量。

程序把回复 POST 到这里，由网关负责真正发出去。

会作为 X-Gateway-Secret 请求头发送，两端要一致。

默认 180 分钟，也就是大约三小时一次。太勤会烦人。

24 小时制，默认 23 点。

默认 8 点，这段时间不会打扰你。

6

语音

语音消息与按键式语音对话
i
语音支持两套后端：默认 OpenAI 兼容音频接口（复用大模型那行地址和 Key）；切到 阿里云百炼 DashScope 后走阿里原生 API，能用 paraformer-v2 / cosyvoice-v2 等中文更强的模型。
对话和语音可以是不同服务商——比如对话用 DeepSeek、语音用阿里百炼，下方 Key 不依赖上方 Key。

选 DashScope 时 ASR/TTS 走阿里原生 API；选 OpenAI 时复用上方 LLM_API_KEY。

百炼控制台单独签发的 sk-...。语音走阿里时用；走 OpenAI 时留空。

语音 → 文字。DashScope 填 paraformer-realtime-v2；OpenAI 填 whisper-1。留空则语音按钮变灰。

文字 → 语音。DashScope 填 cosyvoice-v2；OpenAI 填 tts-1。留空则只能看文字。

要「活泼元气」：OpenAI 选 nova；DashScope 选 sambert-zhixiajia 或 longxiaoyue。

!
网页里能做的是按键式语音对话：录音 → 转写 → 生成回复 → 合成播放。真正的双向实时通话（WebRTC 那种）以及接管微信/QQ 原生语音通话，本方案不做也做不到。

生成配置

一键产出文件

「保存到项目目录」会弹出文件夹选择框，把生成的 .env 和 personas/<id>.yaml 直接写进你的项目文件夹（建议选你的项目文件夹）。选不了就用「下载」两个文件，然后把它们放到项目根目录和 personas/ 下。

  1. 「保存到项目目录」或下载后放置：.env 放项目根目录，personas/<id>.yaml 放进项目根目录的 personas/（没有就新建一个）。
  2. 在项目目录执行 .\setup.ps1 装依赖，然后 .\run.ps1 启动。
  3. 浏览器打开 http://127.0.0.1:8000，先在网页里聊两句，确认人设对味。
  4. 再去接 QQ / 微信：QQ 官方机器人填好即连；微信公众号需要先把端口映射到公网 HTTPS。
